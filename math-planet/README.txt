THE INFINITE LIBRARY — Study with Jasmine

Place this folder at the root of your website, then open /The_Infinite_Library/index.html using Live Server. To link the Math card from the homepage, set its link to ./The_Infinite_Library/index.html.

Contains 168 numbered exercises parsed from the supplied 97-page PDF. The original book is included for exact page/diagram reference. Some math expressions or diagrams may not survive PDF text extraction; check against the source. The game UI is in English, but original problem and solution text remain in Vietnamese, not a fabricated translation.

Features: 9 shelves, search, filters, bookmarks, saved notes, hint, solution reveal, progress tracking, original PDF links, random challenge. All work offline through a local web server except optional Google Fonts.
