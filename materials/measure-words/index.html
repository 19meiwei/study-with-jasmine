THE BASICS

What is a measure word?

量

Measure words

In Chinese, a measure word is normally placed between a number or demonstrative and a noun.

一

Number + Measure Word + Noun

一 + 个 + 人 yí ge rén one person
这

With 这 and 那

这 + 本 + 书 zhè běn shū this book

QUICK REFERENCE

Start with these first

个

个 · gè

The most useful general measure word. When you are a beginner, this is one of the first measure words to learn.

本

本 · běn

Used for books and other bound reading materials.

张

张 · zhāng

Used for many flat objects such as paper, tickets, tables and photographs.
