STUDY WITH JASMINE — Chinese Program (Human Voice Edition)

Install: replace your site's chinese-program folder with this ZIP's chinese-program folder.
Your homepage link stays chinese-program/index.html.

Audio:
- Uses actual native-speaker MP3 recordings from audio-cmn / Shtooka (Yue Tan), CC BY-SA 3.0 US.
- https://github.com/hugolpz/audio-cmn
- https://creativecommons.org/licenses/by-sa/3.0/us/
- MP3 files stream via cdn.jsdelivr.net/gh/hugolpz/audio-cmn@master/64k/hsk/cmn-{Chinese word}.mp3
- Internet required. Not every YCT word or sentence is covered by the source audio library.
- When unavailable, the page displays a message and does NOT play browser-generated TTS.
- For sentence examples, only an exact full-sentence recording would play; most will be unavailable.
- The recordings are NOT taken from Hanzii and the project is not affiliated with Hanzii.
- Attribution and CC BY-SA obligations apply if you redistribute the audio or an adaptation.

Other features: stroke animation requires Hanzi Writer CDN; flashcards, practice, battle and writing studio retained.
This environment could not directly fetch or play the external audio URLs, so actual remote playback must be verified in the browser.
