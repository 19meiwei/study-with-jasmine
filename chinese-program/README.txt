STUDY WITH JASMINE — CHINESE LEARNING STUDIO
Open chinese-program/index.html via VS Code Live Server.

Features:
- Redesigned responsive study dashboard with no AI-generated images.
- YCT 1 existing lesson bank, YCT 2 and YCT 3 separate teacher-created practice banks (96 entries each).
- Flashcards, 4 quiz modes, Hanzi writing, 2-player challenge, vocabulary library.
- New Market Day CSS-based shopping game, timer, 3 lives, points, browser-generated music and SFX.
- Speech: attempts online Mandarin word recordings then falls back to installed Mandarin speechSynthesis voice. It cannot guarantee voice availability; music/SFX work locally after a user click.
- Includes earlier game assets and YCT page images, but scanned books are NOT converted into verified YCT 2/3 textbook-specific vocabulary/sentences. No claim of complete book coverage.
- Note: Hanzi stroke animations depend on external Hanzi Writer CDN and its character data.
- This is a local project package, NOT uploaded to GitHub or deployed.

Install: replace chinese-program directory in website project, then git add ., git commit, git push origin main.
